[중요] 이 PC 는 반드시 '폰 USB 테더링(통신사 모바일 IP)' 으로 인터넷이 나가는
       상태에서 돌려야 합니다. (사무실 유선 IP 를 안 태우기 위함)
       - 폰 USB 연결 + USB 테더링 ON
       - 폰 Wi-Fi OFF + 모바일데이터(LTE/5G) ON
       - 이 PC 의 랜선 뽑고 + Wi-Fi OFF
       스캐너가 실행 첫줄에 공인 IP 를 찍어 사무실 IP 면 경고합니다.

----------------------------------------------------------------------
1) 파이썬 설치 (한 번만)
----------------------------------------------------------------------
  방법A (권장): 브라우저에서  https://www.python.org/downloads/  접속
     - 노란 'Download Python 3.x' 버튼 클릭 → 설치파일 실행
     - ★ 설치 첫 화면 맨 아래 'Add python.exe to PATH' 체크박스 반드시 체크! ★
     - 'Install Now' 클릭 → 끝

  방법B: 명령프롬프트(cmd)에서   winget install Python.Python.3.12
     (윈도우 최신판이면 됨)

  설치 확인: cmd 새로 열고   python --version
     → 'Python 3.x.x' 나오면 성공.

----------------------------------------------------------------------
2) 실행
----------------------------------------------------------------------
  이 폴더(scan_portable)를 통째로 이 PC 에 복사한 뒤,
  폴더 안의  실행.bat  을 더블클릭.
     - 처음 1회는 requests 라이브러리를 자동 설치하고,
     - keywords.txt 를 읽어 스캔 → results.csv 로 저장합니다.

  (또는 cmd 에서 이 폴더로 이동 후:  pip install requests  →  python discover.py)

----------------------------------------------------------------------
3) 사용법
----------------------------------------------------------------------
  - keywords.txt 를 메모장으로 열어, 발굴할 '지역 키워드' 를 한 줄에 하나씩.
  - 실행.bat 더블클릭 → 진행상황이 뜨고, 끝나면 results.csv 생성.
  - results.csv 를 엑셀로 열면  키워드 / 인기탭(O·X)  두 칸.
  - 'O' = 그 지역+키워드에 카페 인기탭이 뜬다는 뜻(발행 후보).

문의사항은 사무실 담당(ERP)에게. 데이터는 키워드당 약 1.5MB 소모.
