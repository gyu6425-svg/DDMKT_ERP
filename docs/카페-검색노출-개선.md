# 카페 검색노출 개선 및 독립검증 가이드

작성일: 2026-07-22  
대상: 누수탐지 자동발행 및 다른 업종 브랜치

## 결론

설고점의 `지역 + 소방업체` 검색 1위 사례는 **검색량·경쟁 문서가 상대적으로 적은 키워드에서 제목 앞부분을 정확히 일치시킨 효과**가 가장 유력하다. 다만 개인화, 최신성, 카페/게시판 공개 설정, 기존 출처 신뢰도 같은 대안 원인을 배제한 자료는 아직 없다. 따라서 같은 제목 형식을 누수탐지에 적용한다고 1위를 보장할 수 없다.

누수탐지는 전용 업체 사이트와 누적 문서가 많은 경쟁 키워드다. 설고점 방식을 그대로 복제하기보다 아래 순서로 검증한다.

1. 제목 맨 앞은 `지역 누수탐지`로 정확히 시작한다.
2. 실제 작업 예시 사진을 사용하되, 사진이 해당 지역·해당 현장이라고 허위로 단정하지 않는다.
3. 같은 배너의 앞뒤 반복을 없애고, 링크는 일부 글에만 넣으며 태그는 4~7개로 줄인다.
4. 발행 후 10분·1시간·6시간·24시간·3일·7일 순위를 로그아웃 상태에서 기록한다.
5. 최소 10~20건이 모인 뒤 제목·실사 사진·구조 중 무엇이 영향을 줬는지 비교한다.

### 발행 절대 조건

`지역 + 누수탐지` 검색 결과에 **인기글 영역이 실제로 확인된 키워드만 발행**한다. 인기글이 없거나, 네이버 응답 오류·차단·파서 실패로 확인하지 못한 경우도 발행하지 않는다. `make_and_queue()` 직접 호출 역시 검증 플래그 없이는 큐 등록을 거부한다.

## 독립검증 결과

### 리서처

- 현재 코드는 `인기글이 하나라도 있는지`만 판정해 경쟁 강도를 구분하지 못했다.
- 누수탐지 검색에는 지역별 전문 사이트와 누적 문서가 이미 많아 소방업체보다 경쟁이 강할 가능성이 높다.
- 검색 노출을 허용한 전체공개 게시판인지 먼저 확인해야 한다. 설정 변경은 검색 반영까지 시간이 걸릴 수 있다.

### 플래너

- 가장 먼저 필요한 것은 더 많은 글이 아니라 **측정 가능한 실험**이다.
- 제목 정확일치는 유지하고, 실사 사진·링크·태그·문서 구조를 한 번에 전부 바꾸지 말고 실험군을 기록한다.
- 발행량은 현재처럼 시간당 약 2개를 넘기지 않고, 같은 지역·같은 키워드 중복 발행을 금지한다.

### 리뷰어

- `1위`가 통합검색 전체 1위인지, 인기글 영역 내부 1위인지 정의가 필요하다.
- 로그인 계정의 개인화 결과만 보면 잘못 판단할 수 있으므로 로그아웃/시크릿 창과 여러 시점 측정이 필요하다.
- 실제 회원 반응은 도움이 될 수 있지만, 가짜 조회·댓글·공감·계정 조작은 사용하지 않는다.

## 이번 코드 반영

`crawler/cafe_pub/cafe_auto_publish.py`

- 인기글 판정 시 같은 검색 응답에서 관측된 카페 URL 수와 review 응답 수를 함께 로그한다.
- 기본 이미지 순서를 `배너 1장 + 실사 6장`으로 바꿨다. 이전 방식은 `CAFE_REPEAT_BANNER=1`로 복원 가능하다.
- 홈페이지 링크는 기본 약 34% 글에만 넣는다. `CAFE_LINK_RATE=0~1`로 조절한다.
- 태그는 기본 4~7개로 줄인다. `CAFE_TAG_COUNT=숫자`로 고정 가능하다.
- 큐 manifest에 `meta.experiment`를 남겨 어떤 조합으로 발행했는지 추적한다. 발행기는 이 블록을 무시하므로 기존 발행 동작에는 영향이 없다.

이미 큐에 들어간 글과 현재 실행 중인 리스너에는 위 변경이 소급 적용되지 않는다. 다음 원고 생성부터 적용된다.

## 사진 사용 원칙

현재 `nusu-real` 이미지는 실제 작업 예시 자료로 사용한다. 사진별 장소와 작업 내용이 확인되지 않은 상태에서는 `종로 현장 사진`, `이 사진에서 배관 파손이 확인됐다`처럼 구체적인 사실을 만들지 않는다. 향후 사진마다 지역·공간·장비·증상 메타데이터를 붙이면 해당 정보 범위 안에서만 본문과 연결한다.

## Caveman / Claude Code

- Claude Code 2.1.216과 `caveman@caveman`을 사용자 범위에 설치했다.
- Caveman의 약 65% 절감 수치는 전체 토큰 보장이 아니라 주로 출력 토큰 평균치다.
- 스킬 자체가 매 턴 입력 토큰을 추가하므로 짧은 답변 위주 작업에서는 절감이 작거나 손해일 수 있다.
- 긴 분석·코딩 세션에서 사용하고, 중요한 검증 보고서는 지나치게 축약되지 않았는지 사람이 확인한다.
- 새 PowerShell을 열고 `claude`를 실행하면 자동 활성화된다. 기존 셸은 PATH 갱신을 위해 다시 열어야 한다.

## 다른 브랜치 적용

이 문서와 `crawler/cafe_pub/cafe_auto_publish.py`를 가져오면 동일한 실험 구조를 재사용할 수 있다. 업종별로 `BUSINESS`, 사진 폴더, 게시판 이름만 분리하고, 같은 카페를 두 PC가 사용할 때는 큐의 `board`와 각 PC의 `CAFE_BOARDS`를 실제 게시판 이름과 정확히 일치시킨다.
