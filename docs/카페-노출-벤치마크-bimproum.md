# 카페 노출 벤치마크: bimproum 분석 (누수탐지 nusu2 본문 양식 근거)

## 목적
카페 글이 왜 통합검색 카페 결과/인기글에 잘 잡히는지 콘텐츠 구조를 분석해, 노출 잘 되는 본문 양식을 만든다.

## 벤치마크(bimproum) 승리 5층 구조
1. 긴 세로 이미지 후기 (현장 사진 몽타주) — 체류시간·신뢰감
2. 검색용 텍스트 본문 — 실제 색인되는 텍스트(이미지는 색인 안 됨)
3. 중간 웹사이트 링크카드
4. 하단 문의 전환 배너
5. 키워드 포함 댓글

## 잘 노출되는 글의 공통 패턴

### 제목
- 핵심 키워드가 제목 맨 앞. 공식: `[지역+서비스] + 정보성 후킹`
- 예: "안성입주청소 눈에 보이는 깨끗함만으로는 부족한 이유", "성남특수청소 악취 원인부터 단계적으로 정리한 과정"
- 피할 제목: 전문업체 추천 / 저렴한 곳 / 문의주세요 / 최고의 서비스

### 본문 흐름(6단계)
1. 최근 해당 지역/서비스를 찾는 이유
2. 실제 현장에서 자주 생기는 문제
3. 작업 범위
4. 업체 선택 기준
5. 특정 업체/브랜드의 운영 방식
6. 마무리 조언

### 본문에서 필요한 신호
- 첫 문단 100자 안에 핵심 키워드
- 키워드 3~6회 자연 반복
- 작업 대상 공간 단어(누수: 천장·벽·화장실·주방·배관·수도관·보일러·옥상·발코니·방수층)
- 문제 상황 단어(누수: 물 얼룩·습기·곰팡이·벽지 들뜸·수도요금 증가·아랫집 피해)
- 업체 선택 기준 단어(누수: 열화상·청음·내시경·수압·최소 파손·정확한 원인 진단·사후)
- 비용보다 작업 범위/숙련도/사후 확인 강조

### 댓글
- RE[키워드] + 실제 궁금증/작업 범위 확인/정보성 반응 (문의형·보충형만, 조작 금지)

## 진단 체크리스트(노출 원인 분석용)
- 제목 맨 앞 키워드 / 제목 정보성 후킹 구조
- 첫 문단 100자 안 키워드 / 본문 키워드 3~6회 / 작업범위 단어 충분 / 문제상황 단어 충분 / 업체 선택 기준 존재
- 긴 현장 이미지 / 웹사이트 링크카드 / 하단 CTA 배너
- 댓글 키워드 Q&A / 동일 게시판 주제집중 누적 / 동일 키워드 과다 중복 발행 회피

## 중요 전제
- 순위 보장 아님. "가능성 높은 원인 + 개선 권장" 형태.
- ★핵심: **긴 세로 이미지는 '이미지'라 네이버가 텍스트로 색인 못 함 → 실제 검색 색인되는 것은 아래 '본문 텍스트'뿐.** 따라서 본문이 얇으면 이미지가 좋아도 검색 손해. 본문에 키워드·작업범위·문제·선택기준을 충분히 담아야 함.
