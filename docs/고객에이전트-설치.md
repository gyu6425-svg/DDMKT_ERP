# 고객 발행 에이전트 — 설치·운영 (Phase 1)

불특정 고객 PC에서 **로그인·스캔·생성·발행** 전 과정을 도는 로컬 에이전트.
웹 UI(호스팅)는 그대로 쓰고, 이 에이전트가 그 PC에서 크롬을 몰고 발행한다.

## 구성
- `agent_main.py` — 단일 진입점: 크롬(헤드리스, CDP) + 브릿지(8788) + 발행 리스너를 한 프로세스로, 자동재시작.
- `nusu2_api.py` — 브릿지(웹 UI가 붙는 곳: 로그인 런치·스캔·연관확장·생성·큐적재).
- `agent.env` — 고객 설정(카페 글쓰기 URL·게시판·프로필·자산폴더 등).

## 사전조건 (Phase 1 = python 설치형)
1. **Google Chrome 설치**(표준 경로).
2. **Python 3.12+** 설치.
3. 의존성: `pip install -r agent-requirements.txt` (playwright·requests·truststore·pillow).
   - ※ `playwright install chromium` **불필요** — 시스템 크롬에 CDP attach 방식.

## 설정
1. `agent.env.example` → `agent.env` 복사 후 채우기:
   - `CAFE_WRITE_URL` = 카페 게시판 '글쓰기' 주소
   - `CAFE_BOARDS`/`CAFE_BOARD` = 게시판명(정확 일치)
   - `CAFE_COMPANY` = 업체 키
   - `CAFE_PROFILE` = 크롬 프로필 폴더명(로그인 세션 저장)
   - `CAFE_ASSETS_DIR` = 업체 자산 폴더(실사·배너; 비우면 repo 기본)
   - `SUPABASE_URL`/`SUPABASE_SERVICE_KEY` (Phase 1 임시 — Phase 2에서 제거)

## 최초 1회: 네이버 로그인
1. 웹 UI **업체 온보딩** 탭 → "네이버 로그인 창 열기"(보이는 크롬, 같은 프로필) → 발행 계정으로 직접 로그인.
2. 그 창을 **닫는다**(같은 프로필을 에이전트가 헤드리스로 이어 씀).

## 실행
- `run_agent.bat` 더블클릭 → 크롬 기동 + 브릿지 + 발행 리스너 가동.
- 웹 UI(발행 스튜디오)에서 스캔·생성 → 큐 적재 → 이 에이전트가 순차 발행.

## 남은 단계(별도)
- **Phase 2**: 서비스키 제거(publishable키+내부인증 로그인) + 생성 CF 경유 → 에이전트에 민감키 0.
- **Phase 3**: PyInstaller(`--onedir`) + Inno Setup 설치마법사 + 코드서명 → **python 불필요, exe 더블클릭**. 자산·설정은 고객별 다운로드.
