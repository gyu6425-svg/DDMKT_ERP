# [집→사무실 인수인계 · 2026-07-29]

어제 집(sub3)에서 카페발행 차단 건 조사·독립검증하고 문서 2개 main에 올림.

## 핵심
마이클 차단은 **발행 문제**이고, 발행은 이미 **실크롬(CDP attach)**이라 라이브러리/TLS지문과 무관.
원인은 **IP·빈도·행동 계층**. → **위장 강화(계정 delink·stealth·지문 스푸핑)는 안 하기로 결론**
(플랫폼 안전장치 우회 + 리스크 비대칭). 실질 조치는 **발행 강도 하향 + 계정↔IP 안정성**.

## 읽을 것
- `docs/네이버-안티차단-조사종합.md` (경로 지도·정정 4건·판단 경계·다음 단계)

## 결정할 것
- (A) 순위 크롤러 `classify_block` 관측 로깅 붙일지
- (B) 마이클 발행 상한/간격 조정
