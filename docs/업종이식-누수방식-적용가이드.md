# 누수 성공방식 → 타 업종(더티클리닉 등) 이식 가이드

> 누수탐지 자동발행에서 **"마포구 누수탐지" 검색 6위 → 2위** 진입을 만든 개선 묶음을, 다른 업종(더티클리닉 입주청소, 더맨, 설고 등)에 그대로 이식하기 위한 양식.
> 기준 코드: `crawler/cafe_pub/cafe_auto_publish.py` (sub2 브랜치). 2026-07-22.
> ⚠️ 네이버 알고리즘은 비공개라 일부 근거는 실무 추정. 하지만 아래는 **실제 순위 상승으로 검증된 조합**이다.

---

## 0. 무엇이 순위를 올렸나 (핵심 5가지)

| # | 개선 | 왜 효과 |
|---|---|---|
| 1 | **실제 작업현장 사진** (템플릿 그래픽 아님) | 네이버 DIA가 "실제 경험 사진"을 정보성 높게 평가 + 이미지 중복 해소 |
| 2 | **글마다 다른 사진·구조** (유사문서 회피) | 지역명만 바뀐 복제글은 유사문서 필터로 누락 |
| 3 | **제목 맨앞 키워드 정확일치** + 첫문단 키워드 | 온페이지 적합도 신호 |
| 4 | **인기글 뜨는(수요 있는) 키워드만 발행** + 경쟁 낮은 순 | 승산 있는 링에서만 싸움 |
| 5 | **꾸준한 발행 → 게시판 주제집중(C-Rank) 누적** | 출처 신뢰도 = 상위노출 바닥점수 |

## 1. 이식할 개선 상세 (누수 코드 위치 → 더티 적용법)

### ① 실사진 풀 + 글마다 랜덤 조합 + 크기
- **누수 코드**: `load_fixed()`(폴더의 모든 사진 로드 + 합성 프레임 좌우 분할) · `make_and_queue()`(풀에서 랜덤 N장 선택+셔플)
- **env**:
  - `CAFE_FIXED_DIR` = 실사진 폴더 절대경로
  - `CAFE_SPLIT_COMPOSITE=1` = 좌우 붙은 합성 프레임을 개별 사진으로 자동 분할
  - `CAFE_PHOTOS_PER_POST=6` = 글마다 쓸 사진 수(풀에서 랜덤)
  - `CAFE_PHOTO_WIDTH=720` = 카페 글 폭에 맞춰 확대(중앙 꽉 참). 0=원본
  - `CAFE_REPEAT_BANNER=0` = 배너 앞뒤 중복 안 함
- **더티 적용**: `public/images/dirty-real/` 에 **입주청소 실제 작업 사진** 넣기. ⚠️ **20~40장 이상** 권장(풀이 작으면 재사용돼 중복). 폴더만 바꾸면 코드는 그대로.

### ② 템플릿 탈피 — 소주제·도입·제목장면 랜덤
- **누수 코드**: `_SECTION_POOL`(14개 소주제에서 매 글 5~6개 랜덤 선택·순서) · `_INTRO_STYLES`(도입 5스타일 랜덤) · `_TITLE_SCENES`(제목 뒷부분 장면 키워드 랜덤)
- **왜**: 고정 흐름을 없애 글마다 구조가 달라짐 → 유사문서 회피
- **더티 적용**: 아래 §2의 **청소 전용 풀**로 교체(내용만 바꾸면 됨).

### ③ 제목 정확일치 + 첫문단 키워드
- **누수 코드**: `_fix_title()` 이 제목을 `"{지역} {BUSINESS}"` 로 강제 시작. `_INTRO_STYLES` 5개 전부 첫 문단이 `"{region} {business}"` 로 시작.
- **더티 적용**: `BUSINESS`만 바꾸면 자동. 제목 = `"{지역} 입주청소 ..."`.

### ④ 키워드 승산 선택 (인기글 + 경쟁 낮은 순 + 서울 구 폴백)
- **누수 코드**: `analyze_popular_pc()`(네이버 실시간 인기글·경쟁 프록시) · `main()` 선별 루프(인기글 통과분을 `cafe_count` 낮은 순 정렬) · `_region_popular_signal()`+`SEOUL_GU`(서울은 "마포"→"마포구" 폴백)
- **env**: `CAFE_SCAN_FACTOR=2`(스캔 깊이), `CAFE_SCAN_DELAY=3`(지역 간 지연 jitter)
- **더티 적용**: `BUSINESS`만 바꾸면 `"{지역} 입주청소"` 로 인기글 확인. **단, 청소는 검색 수요 패턴이 다르니 §3 키워드 발굴로 먼저 스캔** 권장.

### ⑤ 게시판 라우팅 + 중복차단
- **누수 코드**: 큐 `board` 컬럼, `_region_popular_signal` 승격형("마포구") 발행 시 base("마포")도 dedup 처리.
- **더티 적용**: board = `더티클리닉 입주청소`(카페 메뉴명과 **글자까지 정확일치**), 그 PC `.env`에 `CAFE_BOARDS=더티클리닉 입주청소`, `CAFE_BOARD=더티클리닉 입주청소`.

### ⑥ 무중단·충돌 방어
- **3중 방어**(크래시 삼킴·내부 watchdog·좀비 reaper) — 발행 리스너에 이미 있음.
- **gentle 스크래핑** — `analyze_popular_pc` review 서브요청 사이 0.4~0.9초 지연 + 지역 간 jitter → 순위 크롤러와 같은 IP여도 버스트 안 남.
- 더티가 **직접 스크립트(auto_publish_dirty.py)** 라면 이 지연 로직도 이식.

```python

_SECTION_POOL = [
    "입주 전 반드시 확인할 오염·하자 포인트",
    "새집증후군·마감재 유해물질과 환기·베이크아웃",

    "베란다·창틀·새시 레일 찌든때 제거",

    "새집 입주청소", "이사청소", "준공청소", "빈집청소",
    "아파트 입주청소", "화장실 물때 곰팡이", "주방 기름때",
```

## 3. 더티 키워드 먼저 발굴 (누수와 수요 패턴 다름)

누수는 "지역 누수탐지"에 인기글이 떴지만, **청소는 "지역 입주청소 / 지역 이사청소"가 더 뜰 수 있음.** 발행 전 스캔:
- `analyze_popular_pc("{지역} 입주청소")`, `("{지역} 이사청소")` 등으로 **인기글 뜨는 키워드 + 경쟁도** 측정 → 승산 키워드 확정.
- (검색광고 API 키가 있으면 진짜 검색량으로 판정 — `functions/api/naver-keywords.ts` 활용)

---

## 4. 이식 방식 2가지

- **A. 빠른 이식**: 그 PC의 `auto_publish_dirty.py`에 §1 개선(실사진 풀·랜덤·리사이즈·제목/도입/장면 풀·키워드 승산 선택)을 §2 청소 풀로 적용.
- **B. 권장(장기)**: `cafe_auto_publish.py`를 **업종 config 기반**으로 리팩터(웹 `companies.ts`처럼 업종별 BUSINESS/BRAND/board/사진폴더/풀 분리) → 누수·더티·설고·더맨이 **한 엔진 공유**. 새 업종 추가가 config 한 벌로 끝남.

## 5. 이식 체크리스트

- [ ] `public/images/dirty-real/` 에 **입주청소 실사진 20장+** (많을수록↑)
- [ ] `BUSINESS=입주청소`, `BRAND=더티클리닉` 교체
- [ ] `_SECTION_POOL`/`_TITLE_SCENES`/`_INTRO_STYLES`/`_tags` 를 §2 청소용으로 교체
- [ ] board = `더티클리닉 입주청소` (카페 메뉴명 정확일치) · `.env` `CAFE_BOARDS`/`CAFE_BOARD` 일치
- [ ] `.env`: `CAFE_FIXED_DIR`(청소폴더)·`CAFE_SPLIT_COMPOSITE`·`CAFE_PHOTOS_PER_POST`·`CAFE_PHOTO_WIDTH`
- [ ] 발행 전 `analyze_popular_pc`로 청소 키워드 인기글·경쟁 스캔 → 승산 키워드만
- [ ] gentle 스크래핑 지연 이식(순위 크롤러와 IP 공유 시)
- [ ] 발행 후 10분·1시간·1일·3일·7일 순위 로그아웃 상태로 기록해 효과 검증
- [ ] 조작(가짜 조회·댓글·공감) 금지 — 정당한 콘텐츠·키워드 전략만
